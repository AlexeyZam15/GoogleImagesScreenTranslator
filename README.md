## Возможности



📸 **Скриншот окна** — захват и перевод активного окна (F2)  

🖥️ **Скриншот области** — выбор любой области на экране (F3)  

📋 **Очередь переводов** — выделяйте несколько областей подряд (F3), не дожидаясь завершения текущего перевода; все задачи выполняются последовательно в очереди, а результаты отображаются сразу после завершения каждого перевода  

🌍 **Перевод через Google Translate** — использование вкладки "Изображения"  

🖼️ **Оверлей с результатом** — отображение переведенного изображения поверх исходного  

📋 **Горячие клавиши** — полная настройка горячих клавиш в окне настроек (вкладка "Хоткеи")  

🗑️ **Удаление оверлеев** — удаление всех оверлеев (F4) или удаление конкретного оверлея под мышью (ESC в режиме редактирования)  

✏️ **Режим редактирования** — перемещение и удаление оверлеев (F5)  

🌐 **Множество языков** — поддержка перевода на 100+ языков  

⚙️ **Настраиваемый браузер** — выбор браузера (автоматический поиск или ручной путь) с кнопкой "Найти браузеры"  

🔍 **Поиск браузеров** — автоматическое сканирование системы на наличие Яндекс Браузера и Google Chrome  

🔒 **Безопасность** — минимальные права, никаких внешних запросов  

🌍 **Двуязычный интерфейс** — поддержка русского и английского языков

## ⚠️ Важно: Права администратора



### Проблема

Если приложение, которое вы хотите перевести, **запущено с правами администратора** (например, игра, редактор кода или системная утилита), то **горячие клавиши программы Google Screen Translate НЕ БУДУТ РАБОТАТЬ**, если сама программа запущена без прав администратора.



### Причина

Windows блокирует перехват глобальных горячих клавиш из приложений с обычными правами, если целевое окно принадлежит приложению с повышенными правами. Это сделано для безопасности системы.



### Решение

**Запустите Google Screen Translate с правами администратора.**



**Как это сделать:**



1. **Через контекстное меню:**

   - Нажмите правой кнопкой мыши на файл `GoogleScreenTranslate.exe`

   - Выберите **"Запуск от имени администратора"**



2. **Через свойства ярлыка (для постоянного запуска):**

   - Нажмите правой кнопкой мыши на ярлык программы

   - Выберите **"Свойства"**

   - Перейдите на вкладку **"Совместимость"**

   - Поставьте галочку **"Запускать эту программу от имени администратора"**

   - Нажмите **"Применить"** и **"ОК"**



3. **Через командную строку:**

   ```cmd

   runas /user:Administrator "P:\Users\Alexey\Desktop\GoogleScreenTranslate\GoogleScreenTranslate.exe"

   ```

> **💡 Совет:** Если вы часто используете программу для перевода окон приложений, запущенных с правами администратора,

настройте ярлык для постоянного запуска с правами администратора (способ 2).

## 🎮 Использование

### Горячие клавиши (по умолчанию)

| Действие | Горячая клавиша |

|----------|----------------|

| Скриншот окна и перевод | `F2` |

| Выбор области на экране | `F3` |

| Показать/скрыть оверлей | `F1` |

| Удалить все оверлеи | `F4` |

| Режим редактирования | `F5` |

| Удалить оверлей под мышью | `ESC` (в режиме редактирования) |



> **💡 Все горячие клавиши можно переназначить в окне настроек (вкладка "Хоткеи")**

### Особенности работы

- **F2 (скриншот окна)** — делает скриншот активного окна, удаляет все старые оверлеи и показывает результат перевода

- **F3 (выбор области)** — делает скриншот всего экрана, позволяет выделить любую область мышью для перевода. Можно
  выделять несколько областей подряд, не дожидаясь завершения перевода предыдущих — все они будут добавлены в очередь и
  переведены последовательно. Старые оверлеи остаются видимыми

- **F4 (очистка)** — мгновенно удаляет все оверлеи с экрана

- **F5 (режим редактирования)** — включает/выключает режим редактирования, позволяющий перемещать оверлеи мышью и
  удалять их по ESC

- **ESC** — в режиме редактирования удаляет оверлей под курсором мыши; в обычном режиме скрывает все оверлеи

- **📋 Очередь переводов** — выделяйте несколько областей подряд (F3), не дожидаясь завершения текущего перевода; все
  задачи выполняются последовательно в очереди, а результаты отображаются сразу после завершения каждого перевода

### Главное окно

| Элемент | Описание |

|---------|----------|

| Кнопка "Сделать скриншот (F2)" | Захват и перевод активного окна |

| Кнопка "Очистить все (F4)" | Удаление всех оверлеев |

| Кнопка "Показать/скрыть (F1)" | Переключение видимости оверлея |

| Кнопка "Режим редактирования (F5)" | Включение/выключение режима редактирования |

| Выбор целевого языка | Язык, на который будет переведен текст |

| Кнопка "⚙️" | Открыть настройки |

| Кнопка "RU/EN" | Переключение языка интерфейса |

## 🔧 Настройки программы

Все параметры доступны в окне настроек (открывается через меню или по кнопке ⚙️ в главном окне).

### 🌐 Браузер

- **Путь к браузеру** — ручное указание пути к исполняемому файлу браузера

- **Автоматический поиск** — программа найдет Яндекс Браузер или Google Chrome

- **Кнопка "Найти браузеры"** — сканирует систему на наличие браузеров и показывает список для выбора

- **Рекомендуется** — Яндекс Браузер для лучшей совместимости

### 🎨 Интерфейс

- **Показывать индикатор перевода** — отображение прогресса во время перевода

- **Автоскрытие оверлея** — автоматическое скрытие при переключении на другое окно

- **Фулскрин → оконный фулскрин** — автоматическое преобразование при захвате области (F3)

- **Режим редактирования** — разрешить перемещение и удаление оверлеев

### ⌨️ Хоткеи (НОВАЯ ВКЛАДКА)

- **Переназначение горячих клавиш** — нажмите на кнопку с клавишей, затем нажмите новую клавишу

- **Автоматический обмен клавишами** — если клавиша уже занята, она автоматически меняется местами с текущим назначением

- Доступные действия для настройки:

    - Скриншот окна

    - Выделение области

    - Показать/скрыть оверлей

    - Удалить все оверлеи

    - Режим редактирования

### 🌍 Язык интерфейса

- **Русский** — интерфейс на русском языке

- **English** — интерфейс на английском языке

### Целевой язык перевода

- Выбор из 100+ языков

- Поддерживаются все языки Google Translate

- Поиск по названию языка

## 🛠️ Сборка из исходного кода

1. Клонируйте репозиторий:

```bash

git clone https://github.com/AlexeyZam15/GoogleImagesScreenTranslator.git

cd GoogleImagesScreenTranslator

```

2. Установите зависимости:

```bash

pip install -r requirements.txt

playwright install chromium

```

3. Запустите сборку:

```bash

build_exe.bat

```

Готовый файл появится в папке `dist/GoogleScreenTranslate.exe`

## 🐛 Режим отладки

Для диагностики проблем можно запустить программу с параметром `--debug`:

```cmd

GoogleScreenTranslate.exe --debug

```

или через ярлык (в свойствах ярлыка добавить `--debug` в конец поля "Объект").

В режиме отладки:

- Браузер будет показан (не скрыт)

- В консоль выводится дополнительная отладочная информация

- Логирование становится более подробным
