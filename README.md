## ⚠️ Важно: Права администратора



### Проблема

Если приложение, которое вы хотите перевести, **запущено с правами администратора** (например, игра, редактор кода или системная утилита), то **горячие клавиши программы Google Screen Translate НЕ БУДУТ РАБОТАТЬ**, если сама программа запущена без прав администратора.



### Причина

Windows блокирует перехват глобальных горячих клавиш из приложений с обычными правами, если целевое окно принадлежит приложению с повышенными правами. Это сделано для безопасности системы.



### Решение

**Запустите Google Screen Translate с правами администратора.**



**Как это сделать:**

1. **Через контекстное меню:**

   - Нажмите правой кнопкой мыши на файл `GoogleScreenTranslate.exe`

   - Выберите **"Запуск от имени администратора"**



2. **Через свойства ярлыка (для постоянного запуска):**

   - Нажмите правой кнопкой мыши на ярлык программы

   - Выберите **"Свойства"**

   - Перейдите на вкладку **"Совместимость"**

   - Поставьте галочку **"Запускать эту программу от имени администратора"**

   - Нажмите **"Применить"** и **"ОК"**



3. **Через командную строку:**

   ```cmd

   runas /user:Administrator "P:\Users\Alexey\Desktop\GoogleScreenTranslate\GoogleScreenTranslate.exe"

   ```

> **💡 Совет:** Если вы часто используете программу для перевода окон приложений, запущенных с правами администратора,
настройте ярлык для постоянного запуска с правами администратора (способ 2).

## 🎮 Использование

### Горячие клавиши

| Действие | Горячая клавиша |

|----------|----------------|

| Скриншот окна и перевод | `F2` |

| Выбор области на экране | `F3` |

| Показать/скрыть оверлей | `F1` |

| Удалить все оверлеи | `F4` |

| Закрыть оверлей (ESC) | `ESC` |

### Особенности работы

- **F2 (скриншот окна)** — делает скриншот активного окна, удаляет все старые оверлеи и показывает результат перевода

- **F3 (выбор области)** — делает скриншот всего экрана, позволяет выделить любую область мышью для перевода (старые
  оверлеи остаются видимыми)

- **F4 (очистка)** — мгновенно удаляет все оверлеи с экрана

- **ESC** — скрывает все оверлеи (работает глобально)

### Основные шаги

1. **Запустите программу** — откроется главное окно

2. **Выберите способ захвата:**

    - Нажмите `F2` для перевода активного окна

    - Нажмите `F3` для выбора области на экране

3. **Просмотрите результат** — переведенное изображение появится поверх исходного

4. **Нажмите `ESC`** или `F4` — чтобы скрыть или удалить оверлеи

### Главное окно

| Элемент | Описание |

|---------|----------|

| Кнопка "Сделать скриншот (F2)" | Захват и перевод активного окна |

| Кнопка "Выбрать область (F3)" | Захват области на экране |

| Кнопка "Показать/скрыть (F1)" | Переключение видимости оверлея |

| Кнопка "Очистить все (F4)" | Удаление всех оверлеев |

| Выбор целевого языка | Язык, на который будет переведен текст |

| Чекбокс "Показывать индикатор перевода" | Отображение прогресса перевода |

| Чекбокс "Автоскрытие оверлея" | Автоматическое скрытие при переключении окон |

| Меню "Файл" → "Открыть папку приложения" | Открывает папку с настройками и логами |

## 📂 Структура хранения данных

При первом запуске программа создает следующую структуру в папке `Documents/GoogleScreenTranslate`:

```



Documents/GoogleScreenTranslate/

├── config/

│ ├── settings.json # Настройки программы

│ └── overlay_positions.json # Сохраненные позиции оверлеев

├── logs/

│ └── app_*.log # Лог-файлы (хранятся только 5 последних запусков)

└── temp/ # Временные файлы скриншотов



```

**Важно:**

- Настройки сохраняются автоматически при закрытии программы

- Позиции оверлеев сохраняются между сессиями

- Лог-файлы автоматически очищаются, остаются только 5 последних

- Временные файлы удаляются при завершении программы

## 🔧 Настройки программы

Все параметры доступны в окне настроек (открывается через меню или по кнопке ⚙️ в главном окне):

### 🌐 Браузер

- **Путь к браузеру** — ручное указание пути к исполняемому файлу браузера

- **Автоматический поиск** — программа найдет Яндекс Браузер или Google Chrome

- **Рекомендуется** — Яндекс Браузер для лучшей совместимости

### 🎨 Интерфейс

- **Показывать индикатор перевода** — отображение прогресса во время перевода

- **Автоскрытие оверлея** — автоматическое скрытие при переключении на другое окно

### 🌍 Язык интерфейса

- **Русский** — интерфейс на русском языке

- **English** — интерфейс на английском языке

### Целевой язык перевода

- Выбор из 100+ языков

- Поддерживаются все языки Google Translate

- Поиск по названию языка

## 🛠️ Сборка из исходного кода

1. Клонируйте репозиторий:

```bash

git clone https://github.com/AlexeyZam15/GoogleImagesScreenTranslator.git

cd GoogleImagesScreenTranslator

```

2. Установите зависимости:

```bash

pip install -r requirements.txt

playwright install chromium

```

3. Запустите сборку:

```bash

build_exe.bat

```

Готовый файл появится в папке `dist/GoogleScreenTranslate.exe`
