## Возможности

### 📸 Скриншоты и перевод
- **Скриншот окна (F2)** — захват и перевод активного окна
- **Скриншот области (F3)** — выбор любой области на экране для перевода
- **Длительное зажатие F3 (500мс)** — скриншот всего окна + OCR-распознавание всех текстовых зон и автоматическое создание оверлеев
- **Временный перевод (ПКМ в режиме F3)** — оверлей автоматически удаляется через заданное время

### 🧠 Два движка перевода
- **Google Translate** — перевод через Google Images (требует стабильного интернета)
- **Яндекс.Переводчик (OCR)** — перевод с распознаванием текста на изображениях

### 🔄 Автоматизация
- **Автозамена переведённых областей (F6)** — мониторинг экрана и автоматическое отображение перевода при обнаружении той же области
- **Очередь переводов** — выделяйте несколько областей подряд, не дожидаясь завершения текущего перевода

### 🖼️ Управление оверлеями
- **Оверлей с результатом** — отображение переведённого изображения поверх исходного
- **Режим редактирования (F5)** — перемещение оверлеев мышью и удаление по ESC
- **Удаление оверлеев (F4)** — удаление всех оверлеев или конкретного под мышью
- **Контекстное меню в списке окон** — быстрое удаление всех оверлеев для конкретного приложения

### ⚙️ Настройки
- **Горячие клавиши** — полная настройка всех комбинаций
- **Выбор браузера** — автоматический поиск или ручной путь с кнопкой "Найти браузеры"
- **Выбор движка перевода** — Google Translate или Яндекс.Переводчик
- **100+ языков** — поддержка перевода на любой язык
- **Двуязычный интерфейс** — русский и английский

### 🔒 Безопасность
- Минимальные права, никаких внешних запросов
- Версионный контроль — автоматическая очистка устаревших файлов при обновлении

## ⚠️ Важно: Права администратора

### Проблема
Если приложение, которое вы хотите перевести, **запущено с правами администратора**, то **горячие клавиши программы НЕ БУДУТ РАБОТАТЬ**, если сама программа запущена без прав администратора.

### Причина
Windows блокирует перехват глобальных горячих клавиш из приложений с обычными правами, если целевое окно принадлежит приложению с повышенными правами.

### Решение
**Запустите Google Screen Translate с правами администратора.**

**Как это сделать:**
1. **Через контекстное меню:** ПКМ на `GoogleScreenTranslate.exe` → **"Запуск от имени администратора"**
2. **Через свойства ярлыка (постоянно):** ПКМ на ярлык → Свойства → Совместимость → "Запускать эту программу от имени администратора"
3. **Через командную строку:** `runas /user:Administrator "путь\GoogleScreenTranslate.exe"`

## 🎮 Использование

### Горячие клавиши (по умолчанию)

| Действие | Клавиша | Описание |
|----------|---------|----------|
| **Скриншот окна** | `F2` | Захват активного окна и его перевод |
| **Выбор области** | `F3` | Выбор области на экране для перевода |
| **Длительное F3** | `F3` (500мс) | OCR всего окна → все текстовые зоны переводятся автоматически |
| **Показать/скрыть оверлей** | `F1` | Переключение видимости всех оверлеев |
| **Удалить все оверлеи** | `F4` | Удаление всех оверлеев с экрана |
| **Режим редактирования** | `F5` | Включение/выключение режима редактирования |
| **Автозамена** | `F6` | Включение/выключение автоматической замены областей |

> **Примечание:** Все горячие клавиши можно переназначить в окне настроек (раздел "Хоткеи").

### 💡 Дополнительные возможности

| Действие | Описание |
|----------|----------|
| **Временный перевод (ПКМ)** | В режиме F3 нажмите ПКМ вместо ЛКМ — оверлей будет временным и автоматически удалится |
| **Удалить оверлей под мышью** | В режиме редактирования нажмите `ESC` над оверлеем |
| **Удалить оверлеи для приложения** | В главном окне в списке "Окна с переводами" нажмите ПКМ и выберите "Удалить оверлеи" |
| **Очередь переводов** | Выделяйте несколько областей подряд, не дожидаясь завершения текущего перевода |
| **Перетаскивание оверлеев** | В режиме редактирования перетаскивайте оверлеи мышью в любое место |

### Настройка времени жизни временного оверлея
Время жизни временного оверлея настраивается в **Настройки → Интерфейс → ползунок «Время жизни временного оверлея»** (от 10 до 600 секунд).

## 🔧 Настройки программы

Все параметры доступны в окне настроек (открывается через меню или по кнопке ⚙️ в главном окне).

### 🌐 Браузер
- **Путь к браузеру** — ручное указание пути к исполняемому файлу браузера
- **Кнопка "Найти браузеры"** — сканирует систему на наличие Яндекс Браузера, Google Chrome и других Chromium-браузеров
- **Рекомендуется** — Яндекс Браузер для лучшей совместимости

### 🔤 Движок перевода (НОВО!)
- **Google Translate** — стандартный перевод через Google Images
- **Яндекс.Переводчик (OCR)** — перевод с распознаванием текста на изображениях
- При смене движка браузер перезапускается автоматически

### 🎨 Интерфейс
- **Показывать индикатор перевода** — отображение прогресса во время перевода
- **Автоскрытие оверлея** — автоматическое скрытие при переключении на другое окно
- **Автозамена переведённых областей** — автоматический поиск и замена областей на экране
- **Фулскрин → оконный фулскрин** — автоматическое преобразование при захвате области
- **Режим редактирования** — разрешить перемещение и удаление оверлеев
- **Время жизни временного оверлея** — от 10 до 600 секунд

### ⌨️ Хоткеи
- **Переназначение горячих клавиш** — нажмите на кнопку с клавишей, затем нажмите новую клавишу
- **Автоматический обмен клавишами** — если клавиша уже занята, она меняется местами с текущим назначением
- Доступные действия: скриншот, область, показать/скрыть, очистить все, режим редактирования, автозамена

### 🔍 Монитор (для автозамены)
- **Порог уверенности** — настройка чувствительности поиска областей (0.5–1.0)
- **Задержка между сканированиями** — интервал проверки экрана (0.1–2.0 сек)

## 🧠 Как работает OCR всего окна (длительное F3)

1. **Зажмите F3 на 500 мс** — программа делает скриншот всего окна
2. **Перевод через выбранный движок** — изображение переводится
3. **OCR-распознавание** — EasyOCR находит все текстовые зоны на переведённом изображении
4. **Автоматическое создание оверлеев** — для каждой зоны создаётся отдельный оверлей
5. **Добавление в монитор** — каждый оверлей добавляется в систему автозамены (F6)

> **Важно:** Для работы OCR требуется установленный пакет EasyOCR. При первом запуске он загрузит модели (≈500 МБ).

## ⚙️ Требования для работы

### Браузер
Для работы программы необходим один из браузеров:
- **Яндекс Браузер** (рекомендуется)
- **Google Chrome**

Если браузер не найден автоматически, программа предложит указать путь вручную или найти через кнопку "Найти браузеры".

### OCR (для длительного F3)
Для функции OCR всего окна требуется:
- **EasyOCR** — устанавливается через `pip install easyocr`
- При первом запуске загружаются модели (~500 МБ)

## 🛠️ Сборка из исходного кода

1. Клонируйте репозиторий:
```bash
git clone https://github.com/AlexeyZam15/GoogleImagesScreenTranslator.git
cd GoogleImagesScreenTranslator
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
playwright install chromium
```

3. Запустите сборку:

```bash
build_exe.bat
```

Готовый файл появится в папке `dist/GoogleScreenTranslate.exe`

### Версионирование

При сборке программа проверяет версию в файле `version.txt`. Если версия не совпадает с текущей (`APP_VERSION` в
`version_checker.py`), папка приложения в `Documents` очищается для предотвращения конфликтов.
